# Hexagone

Banc d'essai de gouvernance de la France.

À partir de données publiques officielles, Hexagone recrée l'état du pays et permet de tester des décisions (politiques, économiques, budgétaires) dans le respect des règles réelles, puis de comparer les résultats : dette, PIB, emploi, pouvoir d'achat, inégalités, ressenti des gens.

Ce n'est pas un outil de prédiction. Les effets simulés reposent sur des hypothèses visibles et modifiables, affichées avec leur source et une fourchette d'incertitude.

## Statut
